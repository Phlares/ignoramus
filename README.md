# ignorarium

Open research for anyone. A person with an idea and an ordinary computer should be able
to run an experiment that meets publication standards, publish all of it, and let anyone
else replay it from one hash.

ignorarium checks an experiment plan before it runs. Rigor comes from rules the tool
enforces, not from advice. If a check fails, the run does not start.

```
ignorarium --version
```
