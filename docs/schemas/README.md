# Schemas of the `--json` outputs

Each `--json` output of ignorarium is one JSON object. It holds its schema number under `schema`; `report --json` holds it under `card_version`. This folder holds one file per output, for its current number `n` only: `<output>.v<n>.schema.json`, as JSON Schema draft 2020-12. `<output>` is `guide`, `check`, `status`, `status-telemetry` (for `status --telemetry --json`) or `report`. Each number, `card_version` too, rises when a key is removed or renamed, or when a value changes type; a new key keeps the number, so a reader must accept keys it does not know. A file of an older number stays in the git history.
